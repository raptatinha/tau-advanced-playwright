# Chapter 3 - What changed since the video

The video was recorded in 2023. Last reviewed: November 2026.

- **Your user id:** the API needs the id of **your** user in `USERID`. If it is wrong, you get "User Id not correct!". See [how to find it](../TROUBLESHOOTING.md#user-id-not-correct).
- **`tau-playwright`:** this user has a new id, so the one in the video doesn't work anymore.
- **Website:** it looks different from the video.
- **API token:** it is empty in `.env.example`. The tests use the username and password.

Found something else? [Open an issue](https://github.com/raptatinha/tau-advanced-playwright/issues).

Happy Testing 🎭!
